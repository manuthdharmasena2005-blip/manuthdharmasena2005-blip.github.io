# Manuth Dharmasena — GitHub Pages Portfolio

A responsive portfolio website built with HTML, CSS, and JavaScript. It includes entrance/scroll reveal animations, a floating portrait, animated orbit rings, a reading progress bar, mobile navigation, and a copy-email interaction.

## Preview locally
Open `index.html` in a browser. For the best local preview, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload all files and folders from this package. Keep `index.html` at the repository root.
3. Open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save if GitHub asks.
4. Wait a few minutes, then visit `https://YOUR-USERNAME.github.io/`.
5. To submit the assignment, download the repository ZIP from **Code → Download ZIP** and follow the course instructions.

## Personal details to check before publishing
- Confirm the A/L result wording and all achievement dates.
- The home address has intentionally not been published; only Battaramulla, Sri Lanka is shown.
- Referee phone numbers and addresses are not published. Ask referees before sharing their details publicly.
- Only the cleaned PDF CV is included for download. The original DOCX CV is intentionally excluded because it contains private home-address and referee details.

- `script.js`: menu, scroll progress, reveal animations, active section, copy-email button

- `assets/Manuth_Dharmasena_CV.pdf`: downloadable CV
